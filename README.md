# Fajar Green Energy

Proyek ini adalah aplikasi web untuk Fajar Green Energy, perusahaan pengembangan SPKLU (Stasiun Pengisian Kendaraan Listrik Umum).

## Struktur Direktori

- `frontend/` - Aplikasi utama (SPA) yang dibangun menggunakan Vite, React, dan TypeScript.

## Cara Menjalankan

1. Masuk ke direktori `frontend`:
   ```bash
   cd frontend
   ```
2. Instal dependensi:
   ```bash
   npm install
   ```
3. Jalankan server *development*:
   ```bash
   npm run dev
   ```

## Proses Build

Untuk menghasilkan build *production*, jalankan:

```bash
npm run build
```
